# Contributing to mpesa-stk-masked-pin

Thank you for helping make M-Pesa safer for every Kenyan customer.

## Ways to Contribute

### 1 — Star & Share
The single most impactful thing you can do right now is star this repo and
share it with Safaricom developer contacts, fintech communities, and on social media.

### 2 — Report Issues
Found a bug in the demo, a flaw in the proposal, or a security concern?
Open an issue: https://github.com/SamKNato/mpesa-stk-masked-pin/issues

### 3 — Submit a Pull Request

```bash
# Fork the repo on GitHub, then:
git clone https://github.com/YOUR_USERNAME/mpesa-stk-masked-pin.git
cd mpesa-stk-masked-pin
git checkout -b feat/your-feature-name
npm install
npm run dev
# Make your changes, then:
git commit -m "feat: describe your change"
git push origin feat/your-feature-name
# Open a PR on GitHub
```

### 4 — Review the Proposal
Security researchers and fintech engineers: please review `docs/SAFARICOM-INTEGRATION-GUIDE.md`
and open issues or discussions with feedback on the technical approach.

### 5 — Share Merchant Experiences
If you're a merchant or have experienced the PIN visibility problem at checkout,
share your story in GitHub Discussions. Real-world evidence strengthens the proposal.

## Code Style

- TypeScript strict mode — no `any`
- Meaningful comments on all non-obvious logic
- Follow existing file structure and naming conventions

## Commit Convention

```
feat: add new feature
fix: fix a bug
docs: documentation only
chore: tooling / config
```

## Code of Conduct

Be respectful. This is a community effort toward a security improvement that benefits
everyone who uses M-Pesa. Constructive criticism is welcome; personal attacks are not.
